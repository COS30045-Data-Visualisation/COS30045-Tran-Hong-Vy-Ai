# COS30045 Data Visualisation

## Exercise 0.2 – Build Appliance Energy Consumption Website

This repository contains my work for Exercise 0.2 of COS30045 Data Visualisation at Swinburne University of Technology.

The exercise focuses on developing a multi-page website using HTML, CSS and JavaScript to present household appliance energy consumption information.

### Website

The website includes the following pages:

- Home
- Television
- About Us

The website presents information about appliance energy consumption and allows users to explore television energy-related information.

### Technologies Used

- HTML
- CSS
- JavaScript

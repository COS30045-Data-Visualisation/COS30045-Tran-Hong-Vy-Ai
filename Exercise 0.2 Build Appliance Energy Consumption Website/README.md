## About

This website presents an interactive data story about television energy consumption. It explores how screen size and screen technology relate to energy use.

## Pages

- `index.html` — Introduces the Appliance Energy Monitor and provides an overview of the website.
- `television.html` — Presents the television data story and explores screen size, screen technology, and energy consumption.
- `about_us.html` — Provides information about the project and the technologies used.

## Technologies Used

- HTML
- CSS
- JavaScript

## Data Source

The television data used in this project comes from the *Energy Rating Data for household appliances – Labelled Products* dataset published by the Australian Government Department of Climate Change, Energy, the Environment and Water through data.gov.au (Australian Government Department of Climate Change, Energy, the Environment and Water, n.d.).

## References

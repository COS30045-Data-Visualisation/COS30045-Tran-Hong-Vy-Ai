ABOUT OUR WEBSITE

Understanding
Energy Consumption

Appliance Energy Monitor is a website designed to help users explore household appliance energy consumption and understand how everyday electricity use can affect energy costs.

01

Our Purpose

This project presents appliance energy information in a simple and accessible way, helping users become more aware of how household appliances use electricity.

02

What We Provide

The website provides information about televisions and household energy consumption, together with interactive features that make the information easier to explore.

03

Our Goal

Our goal is to make energy-related information easier to understand and encourage users to make more informed decisions about everyday appliance use.

About the Project

This website was developed as part of COS30045 Data Visualisation at Swinburne University of Technology. It demonstrates how HTML, CSS and JavaScript can be combined to create a structured and interactive multi-page website.

Technologies Used

HTML is used to structure the pages, CSS is used for layout and visual design, and JavaScript is used for interactive features such as the FAQ accordion. Git and GitHub are also used for version control.

Data Note

The information currently presented on the website is used to demonstrate the website structure and functionality. More detailed appliance energy data can be incorporated as the project develops.

Generative AI Acknowledgement

Generative AI was used to support the development of this website by helping explain concepts, suggest approaches and assist with debugging. The code was reviewed and adapted by the author.
